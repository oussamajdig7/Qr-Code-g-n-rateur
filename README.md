# QR Code Générateur

Un script Python simple pour générer un QR Code à partir d'une URL saisie par l'utilisateur.

## Prérequis

- Python 3.x
- Bibliothèques requises : `qrcode`, `Pillow`

## Installation

Installez les dépendances nécessaires avec pip :

```bash
pip install -r requirements.txt
```

## Utilisation

Lancez le script :

```bash
python main.py
```

Entrez l'URL lorsque vous y êtes invité. Le fichier `my_qr.png` sera généré localement.
